# Putting the app online with GitHub Pages (~2 minutes, free)

Do this from a computer (drag-and-drop needs a desktop browser).

1. Go to github.com → **New repository** → name it `hapkido-companion` → **Public** → Create.
   (Pages URLs are public either way; this slice contains no school-private material.)
2. On the new repo page, click **"uploading an existing file"** → drag in EVERYTHING
   from this folder: `index.html`, the `data` folder, the `assets` folder, the .md files
   → **Commit changes**.
3. Repo **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → **Save**.
4. Wait ~1 minute, refresh Settings → Pages, and your URL appears:
   `https://YOUR-USERNAME.github.io/hapkido-companion/`

Open that URL on any phone → it runs fully, progress saves in that phone's browser,
and Share → **Add to Home Screen** makes it feel like an installed app.

Updating later: upload replacement files the same way (or git push). Progress on
students' phones survives updates — it lives in their browsers, keyed separately
from the code.
